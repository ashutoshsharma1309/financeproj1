# Keyboard shortcuts

AI CFO supports a few shortcuts to keep you fast.

| Shortcut | Action | Where |
| --- | --- | --- |
| `/` | Focus the page search | App top bar |
| `Esc` | Close the open dialog | Any dialog |
| `Enter` | Submit the focused form | Forms & dialogs |
| `Tab` / `Shift+Tab` | Move between fields and controls | Everywhere |

## Notes

- The `/` shortcut is ignored while you're typing in an input, textarea or other
  editable field, so it never interrupts data entry.
- A `/` hint is shown inside the search box on larger screens.
- All interactive elements are keyboard reachable with visible focus rings — see
  [Accessibility](./ACCESSIBILITY.md).
