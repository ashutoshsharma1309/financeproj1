# Transactions

The transactions ledger (`/transactions`) is a unified list of every income and
expense entry.

## Adding a transaction

Click **Add transaction**, choose **Income** or **Expense**, then set the
description, amount, date, and optionally a category and account. Amounts are
validated to be positive numbers.

## Filtering

- Use the **All / Income / Expense** tabs to filter by type.
- Use the search box to filter by description.

## Summary

Three stat cards show total income, total expense and the net across all
transactions.

## Export

Click **Export** to download the ledger as CSV (type, description, amount, date,
category).

## Notes

Transactions feed the same totals as dedicated Revenue and Expense records, so
you can use whichever entry style fits your workflow.
