# Getting started

A five-minute path from clone to your first insight.

## 1. Install and run

```bash
npm install
cp .env.example .env   # optional for local use
npm run dev            # http://localhost:3000
```

Node 20+ is required (see `.nvmrc`).

## 2. Create your account

Open the app, click **Get started**, and sign up. The first account created
becomes the company **Owner** with full access.

## 3. Set up your company

On the onboarding screen, enter your company name, industry, currency and
fiscal-year start. AI CFO seeds a set of standard income and expense categories
you can customize anytime.

## 4. Add your finances

Record your first entries from **Revenue**, **Expenses** or **Transactions**.
The moment you add data, the dashboard, cash-flow and reports come alive — every
figure is computed from what you entered.

## 5. Ask your AI CFO

Open **AI Assistant** and ask a question like "What's my runway?" or "Why did
expenses change?" The assistant reasons only over your data.
