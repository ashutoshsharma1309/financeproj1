# Modules

AI CFO is organized into focused modules, each reachable from the sidebar.

| Module | Path | Purpose |
| --- | --- | --- |
| Dashboard | `/dashboard` | Financial position at a glance |
| AI Assistant | `/assistant` | Ask questions grounded in your data |
| Transactions | `/transactions` | Unified income/expense ledger |
| Revenue | `/revenue` | Income by source and category |
| Expenses | `/expenses` | Spend by vendor and category |
| Invoices | `/invoices` | Line-item invoices and statuses |
| Cash Flow | `/cash-flow` | Accounts, balance trend and runway |
| Forecasts | `/forecasts` | Scenario projections |
| Reports | `/reports` | P&L and breakdowns with exports |
| Team Members | `/team` | Invite and assign roles |
| Audit Logs | `/audit-logs` | Record of every change |
| Notifications | `/notifications` | Alerts derived from your data |
| Company Settings | `/company` | Profile, categories, preferences |
| Profile | `/profile` | Your personal account |
| Billing | `/billing` | Plan and payment (placeholder) |
| Help Center | `/help` | Guides and answers |

Each finance module supports full CRUD, an empty state when there's no data, and
CSV export where applicable. See the individual guides linked from the
[documentation index](./README.md).
